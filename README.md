# 🎮 WebScoreBoard (점수판)


WebScoreBoard는 여자친구와 보드게임할 때 쓰려고 가볍게 제작한 점수판입니다. 플레이어 이름을 직접 수정해서 사용할 수 있고(새로고침해도 이름과 세트 스코어가 유지됩니다), 세트 승리 시 재생되는 축하 음악을 각자 원하는 곡으로 등록해서 사용할 수 있습니다.

![대시보드 메인 화면](.github/readme/screenshot.png)



---

## 🎵 기본 승리 음악

1. 음원 파일 이름을 `VICTORY.mp3`로 맞춥니다. (대소문자 구분)
2. `assets/` 폴더에 넣어 둡니다.

앱이 `assets/VICTORY.mp3`를 기본 승리곡으로 사용합니다.

> [!TIP]
> 파일이 없거나 재생에 실패해도 에러창 없이 Now Playing 위젯만 조용히 닫습니다.

---

## ⚙️ 설정 · 히스토리 (오른쪽 상단)

오른쪽 위에 **히스토리**와 **설정** 버튼이 있습니다.

### 설정 ⚙
- **WINS +1 시 SCORE를 0으로 초기화**: 켜면 세트 승리 시 양쪽 SCORE가 `0`이 됩니다.
- **RESET 시 WINS도 0으로 초기화**: 켜면 중앙 RESET이 SCORE와 함께 WINS도 `0`으로 돌립니다. (기본은 SCORE만)
- **VICTORY SONG**: Team A / Team B 각각 승리곡을 지정하거나 기본곡(`assets/VICTORY.mp3`)으로 되돌릴 수 있습니다. 팀별 커스텀 곡은 브라우저에 저장됩니다.

### 히스토리 ⏱
- 목록 바로 위에 현재 **SET** 스코어(A:B)가 표시됩니다.
- WINS +1 때 **A vs B** 대결 카드로 기록됩니다. 가운데는 그 판 SCORE, 양쪽에 승/패가 색으로 구분됩니다.
- 기록이 길어지면 목록만 스크롤됩니다.
- **⬇ JSON**으로 `history.json`을 저장하고, **⬆ 불러오기**로 다시 가져올 수 있습니다. (`assets/history.json`은 처음 한 번 시드용입니다.)
- **Clear**로 기록을 지울 수 있으며, 삭제 전 확인 창이 뜹니다. Clear 후에는 새로고침해도 assets 파일이 다시 불러와지지 않습니다.

> [!NOTE]
> 브라우저만으로 `assets/`에 자동 저장은 할 수 없습니다. 히스토리는 브라우저에 두고, 필요할 때 JSON으로 백업하세요.

---

## 🚀 사용 방법

1. 저장소를 클론하거나 소스를 받습니다.
2. (선택) `assets/VICTORY.mp3`를 넣습니다.
3. `ScoreBoard.html`을 브라우저로 엽니다.
4. 카드의 이름을 클릭해 선수 이름을 바꿉니다.
5. SCORE / WINS의 `+1` · `-1`로 점수를 관리합니다.
6. 오른쪽 위 버튼으로 설정·히스토리를 엽니다.
7. 중앙 **RESET**은 SCORE를 `0`으로 돌리고 재생 중 음악을 멈춥니다. 설정에서 켜 두면 WINS도 함께 `0`이 됩니다.
